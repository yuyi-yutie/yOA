# yOA

声明：此README完全由ai编辑

手机优先的个人计划、专注与打卡工具。零第三方依赖，Node.js + SQLite 单进程运行。

## 功能

- **今日计划**：添加、完成、删除；支持「每天 / 每周」重复计划，带频率徽标。
- **重复计划管理**：跳过今天、暂停/恢复、设置结束日期、删除整个系列。
- **专注计时**：25 / 15 / 5 分钟预设，服务端权威计时；锁屏、切后台或刷新后都能按真实时间结算，中途暂停按实际时长记录。
- **完成通知**：HTTPS 下通过 Service Worker 发送系统通知。
- **每日打卡**：连续天数统计。
- **访问安全**：单密钥 + 服务端 scrypt 哈希，支持应用内改密钥、登录限流与 CSRF 防护。

## 快速开始

```powershell
npm start
```

首次启动的访问密钥为 `admin`，登录后请在「关于」页修改。详细部署、HTTPS 与配置说明见 [DEPLOY.md](DEPLOY.md)。
